Step 1: Start MySQL
   Windows XAMPP: Click "Start" on MySQL in XAMPP panel
   Linux: sudo service mysql start
   macOS: brew services start mysql

Step 2: Run Migrations
   cd backend-fresh
   php artisan migrate --step

Step 3: Clear Cache
   php artisan config:clear

Step 4: Visit Dashboard
   http://localhost:8000/admin/leads

🆘 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════

Issue: "No connection could be made"
→ MySQL not running - Start MySQL service

Issue: "Table already exists"
→ Migration already ran - Skip or rollback

Issue: No statistics showing
→ No leads in system - Submit test form first

Issue: Email not sending
→ Check MAIL_* settings in .env file

Issue: Search not working
→ Clear browser cache, try again

Full troubleshooting in: INSTALLATION_GUIDE.md
